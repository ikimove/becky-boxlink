# Becky! BoxLink

Becky! Internet Mail のメール作成画面から Box にログインし、フォルダの共有リンクを作成して本文に挿入するプラグインです。

- 共有リンクに **有効期限** と **ワンタイムパスコード（メール認証）** を任意で設定できます
- ワンタイムパスコードで許可するメールアドレスは、作成中メールの宛先（To / Cc / Bcc）から自動で取り込みます
- Box API の呼び出しは必要最小限です（フォルダは展開したときだけ取得、共有リンクは 1 回の呼び出しで作成）

## 動作環境

- Becky! Internet Mail 2.8 以降（32bit 版）
- Windows 10 / 11
- Box の Business プラン以上（ワンタイムパスコードを使う場合）

## インストール

1. [Actions](../../actions) または [Releases](../../releases) から `BoxLink-x86` をダウンロードします
2. `BoxLink.dll` を Becky! の `PlugIns` フォルダ（例: `C:\Becky!\<ユーザー>\PlugIns\`）にコピーし、Becky! を再起動します
3. メール作成画面の本文を右クリック →「Box 共有リンクを作成...」を選びます
4. 初回は `<データフォルダ>\PlugIns\BoxLink.ini` が作られます。Box アプリの情報は下記のとおり環境変数に設定してください

## Box アプリの準備（管理者・初回のみ）

1. [Box Developer Console](https://app.box.com/developers/console) で「Platform App」→「ユーザー認証 (OAuth 2.0)」のアプリを作成
2. 「構成」タブで次を設定
   - リダイレクトURI: `http://localhost:53682/callback`
   - アプリケーションスコープ: 「Box に格納されているすべてのファイルとフォルダへの読み取り/書き込み」
3. クライアントID・クライアントシークレットを **ユーザー環境変数** に設定（設定ファイルには書きません）
   - `BOXLINK_CLIENT_ID` … クライアントID
   - `BOXLINK_CLIENT_SECRET` … クライアントシークレット
   - 設定方法: Becky! の「ツール → プラグインの設定」で BoxLink を選ぶと開く **設定画面** で入力できます（Windows の「環境変数を編集」画面や、PowerShell の次のコマンドでも可）
     `[Environment]::SetEnvironmentVariable('BOXLINK_CLIENT_ID', '<ID>', 'User')`
4. 社内の Box 管理者による承認が必要な場合は、管理コンソールでアプリを有効化してもらいます

## 使い方

1. 「ログイン」を押すとブラウザが開きます。Box にログインしてアクセスを許可してください（次回以降は不要）
2. 共有するフォルダを選びます（「最近使ったフォルダ」からも選べます）
   - 中身を確かめたいときは、フォルダを選んで「ファイル表示」を押すと直下のファイル（名前とサイズ）がツリーに追加されます。ファイルは表示のみで、共有リンクはフォルダに作成します
3. 有効期限・ワンタイムパスコード（許可するアドレス）・ダウンロード可否を設定し、「作成して挿入」を押します
4. 本文のカーソル位置にリンクが挿入されます（クリップボードにもコピーされます）

読み込んだフォルダ一覧は 10 分間覚えておき、ダイアログを開き直しても Box に問い合わせません。他の人が Box 上で行った変更をすぐ反映したいときは「最新表示」を押してください。

既に共有リンクがあるフォルダでは URL は変わらず設定だけが更新されます。ワンタイムパスコードの許可リストは既存の分をすべて削除し、今回チェックしたアドレスだけに置き換えます。

## 設定画面

Becky! の「ツール → プラグインの設定」で BoxLink を選ぶと設定画面が開きます。

| 項目 | 保存先 |
|---|---|
| クライアントID / クライアントシークレット | ユーザー環境変数（シークレットは画面に表示しません。空欄のままなら変更しません） |
| リダイレクトポート | `BoxLink.ini` `[box]` |
| 有効期限・ワンタイムパスコード・ダウンロード許可の既定値 | `BoxLink.ini` `[link]` |
| 起点フォルダ ID | `BoxLink.ini` `[browse]` |
| 最近使ったフォルダの消去 | `BoxLink.ini` `[recent]` |
| 本文への挿入方法 | `BoxLink.ini` `[insert]` |

共有ダイアログで未設定のまま「ログイン」を押したときも、この画面を開けます。

## フォルダ一覧の起点

`BoxLink.ini` の `[browse]` で、ツリーに表示する起点フォルダを指定できます。指定したフォルダの下だけが一覧に表示され、共有リンクもその下のフォルダにのみ作成できます（起点フォルダ自体は共有対象外）。

```ini
[browse]
root_folder_id=123456789     ; https://app.box.com/folder/123456789 の数字。0 ならすべてのファイル
```

ダイアログでフォルダを選んで「起点に設定」を押しても設定できます（起点を選んで押すと解除して「すべてのファイル」に戻ります）。

ツリーには Box 上のフォルダ名が表示されます。名前は起点の ID を変えたときに1回だけ API で取得し、`[cache]` に保存して使い回します。起点を変えると、「最近使ったフォルダ」は新しい起点の下で作成したものだけが表示されます。

## ファイルの場所

| ファイル | 内容 |
|---|---|
| `<データフォルダ>\PlugIns\BoxLink.dll` | プラグイン本体 |
| `<データフォルダ>\PlugIns\BoxLink.ini` | 設定（有効期限の既定値・起点フォルダなど）と最近使ったフォルダ |
| `<データフォルダ>\PlugIns\BoxLink\token.dat` | ログイン情報（Windows の DPAPI で暗号化。同じ Windows ユーザーでのみ復号可能） |

## ビルド

GitHub Actions（`.github/workflows/build.yml`）で `main` への push ごとにビルドされます。`v*` タグを push すると Release が作成されます。

ローカルでビルドする場合（Visual Studio 2022 Build Tools と CMake が必要）:

```
cmake -S . -B build -A Win32
cmake --build build --config Release
```

設計の詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。
